# Academia Sinica Open House map

An interactive itinerary for Academia Sinica's October 17, 2026 Open House in Nangang, Taipei. Includes 15 selected activities at six locations, activity descriptions, opening hours, and walking navigation links.

This is a personal, unofficial itinerary. Event times and participation rules are subject to the organizers' announcements. The visual style is inspired by the official Open House website.

## Website

The site is a static HTML page. Open `index.html` in a browser, or enable GitHub Pages from the `main` branch and the repository root. No build step is required.

The map uses D3 7.9.0 from jsDelivr. Activity selection stays in the visitor's browser using local storage.
